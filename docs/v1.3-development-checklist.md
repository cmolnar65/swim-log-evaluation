## Working rules

Develop only on develop, with focused commits and SHA/check reporting. Preserve data, privacy, access controls, backward compatibility, WordPress minimum 6.2 and PHP 7.4–8.5 support. Read actual Plugin Check diagnostics; no broad suppression. Keep narrow architectural exceptions individually documented.

No main modifications/merge, tags, releases, distribution ZIP builds or SVN changes without explicit authorization. Stage-only validation is permitted and creates no distribution archive. Never commit confidential PDFs, private extracted content, credentials or personal health response payloads. Keep historical changelogs intact and release/schema versions distinct.
