# v1.3 step 08 — measurement calendar presentation

One text-labeled badge per measurement category/day follows recorded swims, planned workouts and events. Desktop month/week cells and the touch agenda use bounded previews. When items exceed the preview's measured height budget, later items are hidden and an accessible ellipsis button opens the existing full-day modal. Hidden preview items remain present in the full list; no stored readings are discarded.

The day modal keeps all existing workout/plan/event actions first, then private measurement details. Reports, samples and aggregates retain distinct roles. Garmin's average, sleep average and seven-day baseline have explicit labels. Source, supplied UTC/local times, units, imported reading count and conflict notices are shown. No new calculated average or clinical conclusion is introduced. Current import limitations from step 06 remain.

The owner-only browser fetch uses the separate nonce-protected measurement route, same-origin credentials and a server-rendered current-owner capability flag. Cross-user calendars do not enable health requests. No health values are embedded in server-rendered calendar HTML. Failed health reads show independent status/retry and do not hide workouts or claim an empty/zero measurement. Late/aborted navigation responses cannot populate a different range or closed dialog.

Text is inserted with textContent. Badge names include text rather than relying on icons/color. Controls meet 44px touch height. The existing native modal contains focus, scrolls within the viewport, closes by Escape/Close/outside tap, restores focus to its trigger (or the day button if responsive reflow replaces it), and retains rotation handling. Preview overflow is recalculated after resizing; full modal contents are not clipped.

Production JavaScript/CSS browser tests cover one badge per category/day, workouts-first ordering, ellipsis opening, complete scrollable lists, average/baseline labels, multiple weight readings, focus, rotation, existing actions and measurement failure/retry. Run on desktop Chromium, Android-sized touch Chromium and iPhone-sized touch WebKit. Backend privacy and nonce tests continue unchanged.

No schema/version increment, distribution ZIP, main/tag/release or SVN change.
